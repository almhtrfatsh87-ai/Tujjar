TUJJAR - نسخة تجريبية أولية
================================

التشغيل:
1) فك ضغط ملف Tujjar.zip.
2) افتح index.html في متصفح حديث.
3) استخدم زر English / العربية لتبديل اللغة.
4) اختر الدولة والعملة من أعلى الصفحة.
5) أضف المنتجات إلى السلة.
6) جرّب زر "افتح متجرك" لإضافة منتج تجريبي.

النشر المجاني:
- ارفع الملفات الثلاثة (index.html و style.css و app.js) إلى مستودع GitHub.
- من Settings > Pages اختر Deploy from a branch.
- اختر main ثم /(root) ثم Save.
- انتظر حتى يظهر رابط الموقع.

مهم جدًا:
هذه نسخة واجهة أمامية تجريبية. البيانات تحفظ محليًا في نفس المتصفح فقط.
لا يوجد حتى الآن تسجيل دخول حقيقي، أو قاعدة بيانات مشتركة، أو دفع إلكتروني،
أو شحن دولي، أو لوحة إدارة آمنة. لا تستخدمها لاستقبال مدفوعات أو بيانات حساسة.
لتحويلها إلى منصة متعددة البائعين حقيقية، نحتاج في المرحلة التالية إلى Backend
وقاعدة بيانات ومصادقة وصلاحيات، ويمكن دراسة خطة مجانية مثل Supabase مع حدودها.
العملات المعروضة هنا هي اختيار تنسيق فقط وليست أسعار صرف محوّلة تلقائيًا.
